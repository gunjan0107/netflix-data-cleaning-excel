# Netflix Data Cleaning & Basic Visualization

## Project Overview
This project prepares the Netflix titles dataset for analysis and uses basic Excel visualizations to explore the catalogue. It is designed to demonstrate foundational data-cleaning, data-validation, and charting skills.

## Objective
- Inspect the dataset's structure and fields.
- Check for missing values, duplicate records, and inconsistent entries.
- Prepare a usable analysis table.
- Create basic visualizations to summarize the content catalogue.

## Dataset
The dataset supplied for this project contains **8,790 records** and these fields:

`show_id`, `type`, `title`, `director`, `country`, `date_added`, `release_year`, `rating`, `duration`, `listed_in`

Keep the original dataset unchanged and document any cleaning decisions in the workbook.

## Tools
- Microsoft Excel
- CSV dataset

## Workflow
1. Import the CSV into Excel.
2. Review column names, data types, and sample records.
3. Check for blank or missing values and duplicate records.
4. Standardize values only where necessary, keeping a record of changes.
5. Convert the cleaned range into an Excel Table.
6. Create basic charts such as content type distribution and titles by release year.
7. Add a short summary of the findings.

## Questions Explored
- How many Movies and TV Shows are represented?
- How is the catalogue distributed by content type?
- Which release years have relatively high title counts?
- Which fields require additional data-quality checks?

## Initial Dataset Facts
- Total records: **8,790**
- Movies: **6,126**
- TV Shows: **2,664**
- Release-year range: **1925–2021**

These figures describe the supplied dataset and are not necessarily the number of titles currently available on Netflix.
